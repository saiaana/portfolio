# Portfolio

A personal portfolio site built with React, TypeScript, and Tailwind CSS. Features project showcases with image sliders, multilingual support (English, Russian, Korean), and a responsive layout.

## Tech stack

- **React 19** + **TypeScript**
- **Vite 7** — build tool
- **Tailwind CSS** — styling
- **react-i18next** — internationalization (EN / RU / KR)

## Getting started

```bash
# Install dependencies
npm install

# Run dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Scripts

| Command   | Description              |
| --------- | ------------------------ |
| `npm run dev`     | Start dev server (Vite)  |
| `npm run build`   | Type-check + production build |
| `npm run preview` | Serve production build   |
| `npm run lint`    | Run ESLint               |
| `npm run format`  | Format with Prettier     |
